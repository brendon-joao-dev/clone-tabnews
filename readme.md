# 📰 Clone TabNews

> Clone do [TabNews](https://www.tabnews.com.br/) desenvolvido durante o curso.dev, do Filipe Deschamps, como projeto prático de estudo full-stack.

## 🎯 Sobre este repositório

Este repositório contém o código desenvolvido por mim ao longo do **curso.dev**, curso ministrado por **Filipe Deschamps**, cujo projeto principal é a construção de um clone completo do [TabNews](https://www.tabnews.com.br/) — uma plataforma de notícias e discussões voltada à comunidade de tecnologia.

O objetivo do curso é ensinar, na prática, conceitos de desenvolvimento de software modernos: testes automatizados, integração contínua, infraestrutura, banco de dados, autenticação, segurança e boas práticas de arquitetura — construindo um produto real do zero.

```
📁 pages/            → rotas e páginas da aplicação

```

## 🛠️ Tecnologias utilizadas

- Node.js
- React.js

## ▶️ Como executar

```bash
# clone o repositório
git clone [link-do-repositorio]

# entre na pasta do projeto
cd [nome-da-pasta]

# instale as dependências
npm install

# suba os serviços de infraestrutura (banco de dados, etc)
npm run services:up

# rode as migrations
npm run migrations:up

# inicie o ambiente de desenvolvimento
npm run dev
```
